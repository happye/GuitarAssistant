## 验收标准

- 对 3 种谱源（书页/截图/打印谱）识谱可用率达标（§9 M2）；可重拍重试；渲染与源谱一致、点按试听音高与 midi() 一致
- 讲解基于结构化数据：同一段谱两次讲解结论一致（不重新看图重讲）；能指导实际按弦；≥20 音样例谱覆盖审计 0 漏音 0 重复、每句含 finger 字段、术语首现带一句解释
- Guitar Pro 导入 3 个不同版本抽查一致；移调/变调夹 C→G 上移 5 品等 ≥10 组用例全对（单元测试）
- 指法 DP：爬格子/C-Am-G-F 和弦进行等 ≥10 组用例符合常识，非法指法被规则校验拦截（单元测试）

## 决策与备注

- 识别与讲解分离：识谱只产出可校验/可回放/可编辑的 TabDocument，讲解基于结构化数据——避免"每次问都重新看图、每次讲得不一样"（§8.1 设计要点）
- 逐句讲解走"结构化优先"路线 B，不做模型直接看图即席讲解：防漏音可程序化审计、图只编码一次、点哪讲哪依赖结构化索引（§8.7）
- 切分粒度三层：段落级概览 → 乐句级讲解（默认单元，2-4 小节）→ 音符级点读兜底；固定结构：总述→左手→右手→术语大白话→难点→自查（§8.7）
- 防漏音 CoVe 覆盖审计：讲解后剥离文本、仅凭 TabDocument 重列音符清单做集合比对，不一致则重写（§8.7）
- 自动指法自研 DP（换弦/跨把位/伸展代价，参考 MIT 6.006 与 arXiv:2407.09052）；不存在拿来即用的开源指法库（§8.7）
- 交互分期：本里程碑 = Phase 1 乐句卡片式点读 + 整段 TTS 朗读；逐音高亮跟播（Phase 2）、先讲后练闭环（Phase 3）后置（§8.7）
