# M3 视觉教练 —— v0.4.0

- 状态：⬜ 未开始
- 目标：让手机摄像头成为"盯着你看的教练"：实时手部跟踪叠加（CameraX + MediaPipe）、姿势规则警报（0ms 层）、关键帧 AI 点评 + TTS 播报

## 范围与状态

| 特性 | 内容 | 状态 |
|---|---|---|
| F301 | 相机实时手部跟踪叠加：CameraX ImageAnalysis + MediaPipe HandLandmarker（LIVE_STREAM、GPU delegate）→ Canvas 骨架叠加 | ⬜ 未开始 |
| F302 | 姿势规则警报（0ms 层）：折腕（肘-腕-食指 MCP < 165°）、指尖-关节塌陷、拇指位置分区、双手在框检测 | ⬜ 未开始 |
| F303 | 关键帧 AI 点评 + TTS 播报：手在框内 + 每 90~120s（或姿势突变）采 1~3 帧 → reviewHandFrames（JSON）→ 卡片 + 系统 TTS 播报 | ⬜ 未开始 |

## 验收标准

- 近五年机型 ≥30fps 实时叠加；手出画面时叠加消失且给出引导
- 刻意折腕/塌指 1 秒内出警报；正常手型不误报（误报率 §9 M3 可接受）
- 爬格子练习中获得实时警报与有用点评；点评单次 ≤2 条、可执行；手不在画面时不产生幻觉点评

## 决策与备注

- 单目手机摄像头做不到可靠判品（透视/遮挡/分辨率/动态标定）——不承诺判品；视觉只做有把握的事：姿势类判定即时警报（§5.4）
- 约束场景而非对抗物理：手机支架固定机位（琴颈斜前方 45° 引导页）、练习内容低把位起步；支架是必备外设（§5.4 / §8.2）
- 三层反馈环：规则层 0ms 判定 + 关键帧视觉点评；提示词内置"看不清就说，不硬猜"约束防误报（§8.2）
- TTS 用 Android 系统 TTS（中文、零成本），不引第三方（§8.5）
- 前置依赖：M3 前下载 hand_landmarker.task 入 assets（ROADMAP 对外依赖待办）
