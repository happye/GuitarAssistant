# F604 评估记录：扒谱云端增强（Demucs 分离 + 云端转写）

> 日期：2026-09-16 ｜ 结论：**不上线 v1**（端侧 MVP 优先，云端增强按需后置）
> 依据：开发方案 §8.8。

## 评估

| 维度 | 评估 |
|---|---|
| 正确率 | 云端 Demucs 分离 + 高配转写理论上优于端侧（失真/混音素材的"高清模式"），但端侧 MVP 主打清音单音已满足 v1 场景；云端收益集中在端侧做不到的素材 |
| 成本 | GPU 按量预估单次 0.1~0.5 元（方案 §8.8）；个人项目无付费通道，引入即需支付/账号/密钥服务端化（与"密钥不出本机"红线冲突，需自建轻量代理） |
| 耗时 | 上传+分离+转写+回传，分钟级；端侧秒~十秒级 |
| 法务 | 版权免责声明必须先行（用户上传受版权保护素材）；个人使用阶段无对外服务主体，不上线即无此负担 |

## 决策

**不上线 v1**。端侧链路（F601 抽 PCM → F602 转写 → F603 弦品分配）先行并如实标注质量边界（清音单音良好、失真/混音不承诺）；云端增强等真实使用反馈证明"清音转写够用、失真素材有强诉求"后再立项，届时同步设计付费与代理方案。
