# 功能扩展竞品调研（feature-research · 2026-09-17）

> 目的：为 GuitarCoach 下一阶段选型找「集百家之长」的扩展方向。
> 调研方式：WebSearch 工具当日 403 不可用，全部改用 mcp__bocha__bocha_web_search；信源以应用商店/下载站产品描述与官网为主，**曲库量、识别精度等数字均为官方宣传口径，立项前需复核**。
> 口径约定：适配度=高/中/低；工作量 small(≤1天)/medium(2-5天)/large(>1周)，均按现有基建假设。基建缩写：TD=TabDocument 唯一谱面模型，TP=TonePlayer/合成播放，MPM=现有音高检测，Room=练习记录/曲库库，LLM=网关（DeepSeek+GLM 流式降级），DP=F209/F603 弦品指法内核，alphaTab=1.8.4 渲染+SoundFont。

---

## 0. 评估基准：本项目已有能力（适配判断的锚点）

- 识谱三通道（粘贴/拍照/GP 导入）→ TD；alphaTab 渲染 + 点按试听（F202）
- 逐句讲解（F207/F208）、乐理问答、音色向导（F503）、AI 周复盘（F501）——LLM 链路成熟
- 调音器 MPM（F005）、节拍器 BPM+重音（F105）、跟练判定时序对齐（F401）、音高曲线（F402）、视听互验（F403）
- MediaPipe 手部跟踪 + 姿势警报 + TTS 点评（M3）
- Room：练习记录/会话/曲库（F106/F107/F502）；指法 DP（F209）；移调/变调夹计算器（F206）
- 扒谱基建：PCM 抽取（F601）+ 弦品 DP（F603）；F602 转写阻塞、F604 云端已决策不上线

**用户点名要补的「能用」短板：谱面整体播放、速度训练、和弦库。**

## 1. Songsterr —— 谱面播放器的黄金标准

| 功能点 | 适配度 / 工作量 | 评估理由（依赖什么 / 是否新依赖） | 实现思路（结合现有基建） |
|---|---|---|---|
| 整曲播放 + 光标跟随/自动滚动 | 高 / small-medium | alphaTab 自带 AlphaSynth 播放引擎与播放位置事件，无新依赖；F202 已有 SoundFont 合成与点按试听，只差播放器接线 | F202 基础上加 play/pause + position 事件驱动光标高亮与自动翻页滚动；「谱面整体播放」短板一步补齐 |
| 速度控制（宣传可降至 15%） | 高 / small | alphaTab playbackSpeed 参数即得，无新依赖 | 播放器加 0.15x–1.0x 变速滑杆，与速度训练共用同一变速通道 |
| 段落循环（选定小节反复） | 高 / small | alphaTab playbackRange 支持区间循环 | 选中小节设 loop 区间；作为速度训练的载体 |
| 分轨 Solo / Mute（多乐器分轨） | 高 / small-medium | GP 导入（F205）已带多轨信息；alphaTab 有 track mute/solo/volume API | 曲目详情页出轨道列表（音量/静音/独奏），只动渲染播放层，TD 不变 |
| 音调变换（整体变调免重调弦） | 高 / small | TD 全量移调 + F206 移调计算器已有换算内核 | TD 统一 ±n 半音后重渲染；同时给出变调夹替代方案（复用 F206） |
| 预备拍 count-in | 高 / small | 节拍器合成音已具备出声能力（F105/TP） | 播放前播 1 小节 click，与节拍器共用合成器 |
| 原曲官方音频同步播放 | 低 / large | 需正版音源授权，法务+版权成本双高 | 不做；替代口径见 §6「原曲变速跟练」（用户自带本地音频） |
| AI：粘贴视频链接生成谱 | 低 / large | 需云端转写+内容法务，与 F604「云端不上线」决策一致 | 暂不做；扒谱继续走端侧 F602 路线（干净单音场景） |
| 离线缓存/收藏/历史 | — | 曲库 Room（F502）+ TD 持久化已覆盖 | 无需立项 |

## 2. Ultimate Guitar —— 谱面工具箱 + 音色生态

| 功能点 | 适配度 / 工作量 | 评估理由 | 实现思路 |
|---|---|---|---|
| 谱面移调 + Simplify（简化复杂谱） | 高 / small-medium | 移调复用 F206；「简化」可先规则化（去装饰音/降密度/去技巧标记），LLM 辅助兜底 | TD 变换管线产出「简化版副本」入曲库，与原版并存对照 |
| 自动滚动（纯浏览，不播放） | 高 / small | 纯 UI 滚动，无音频依赖 | 按 TD 的 BPM 估算滚动速率匀速翻页，为无 SoundFont 场景兜底 |
| 和弦库 + 和弦图（200 万+） | 高 / small-medium | 静态数据+自绘，无新依赖；冷门和弦可用 LLM 生成但必须过 F209 指法规则校验 | 预置常用和弦指法数据（CAGED 推导生成 JSON）→ Canvas 和弦图 → TP 琶音/扫弦试听；「和弦库」短板直接补齐 |
| Tab Pro 交互式播放（多轨/循环/变速） | 高 / small-medium | 与 Songsterr 条目同构 | 合并进「播放器强化」一个专项，不重复立项 |
| Tonebridge 式「按歌给音色预设」 | 高 / small-medium | F503 音色向导已是此方向；LLM 可生成参数，无新模型 | 曲目页挂「音色预设卡」：Gain/EQ/Delay/Reverb + 拾音器档位提示，预设存 Room 可复用 |
| 个人谱编辑器 | 中 / medium | F203 识谱结果编辑已有雏形，扩展成全谱编辑器成本高 | 不单独立项，逐步给 F203 增删小节/音符的能力 |
| 左手模式/字号/夜间模式 | 高 / small | 纯 Compose UI 设置项 | 设置页加布局镜像与字号档位 |
| 打印 / 导出（PDF/MIDI） | 中 / small-medium | MIDI 导出需自写标准 MIDI 文件 writer 或验证 alphaTab 导出能力；PDF 走 Android PdfDocument | TD→MIDI writer（几百行，音符数据齐全）；价值中等，排在播放器之后 |
| 社区/评分/演奏视频 | 低 / large | 需后端+内容审核+冷启动 | 不做 |

## 4. 调音器细节（GuitarTuna / Fender Tune）

| 功能点 | 适配度 / 工作量 | 评估理由 | 实现思路 |
|---|---|---|---|
| 调弦预设库（26 种：Drop D/DADGAD/Open G/降半音等） | 高 / small | MPM 检测与调弦无关，纯配置；GP 导入谱的调弦标记可直通 | 目标音高表配置化；打开谱面提示「该谱使用 Drop D，一键切换调弦」 |
| 自动认弦 + 免提逐弦引导 | 高 / small | 检测音对目标弦做最近匹配即可，无新依赖 | 「自动模式」状态机：拨弦→认弦→偏差收敛→打勾切下一弦 |
| 音分指针表盘 / 赫兹显示 | 高 / small | 纯 UI 可视化 | 偏差 ±50 音分指针仪表 + 实时频率数字 |
| 噪声鲁棒（嘈杂环境可调音） | 中 / small-medium | MPM 前加能量门限/中值滤波可起步；深度降噪需 DSP 投入 | 先做 SNR 估计+置信度显示，低置信不报音名（诚实口径，与 F404 同风格） |
| 基准音 A=420-460Hz 可调 | 高 / small | 一个常量+重算 | 设置项（435 音乐会音高/442 乐队常用） |
| 和弦学习游戏 / 听辨训练 | 中 / small-medium | TP 可出参考音；内容轻量 | 两类小游戏：看图选和弦名、听音程/和弦选答案；成绩入 Room |
| 交互琴头点弦听音 | 高 / small | 音名→频率换算已有（F206/MIDI 计算） | 点琴头图听该弦标准音，辅助纯听调弦 |

| 功能点 | 适配度 / 工作量 | 评估理由 | 实现思路 |
|---|---|---|---|
| 本地音频 → 和弦进行 | 中 / medium | 端侧 chromagram+和弦模板匹配（HMM/Viterbi 平滑）无需新模型；准确率天花板约 70-80%（宣传口径约 80%，以大三/小三为主），必须配手动修正 | 复用 F601 抽 PCM → chroma 特征 → 模板匹配+平滑 → 和弦事件序列；标注「参考，可点选修正」，修正 UI 复用 F203 雏形 |

## 6. Moises / Riffstation —— 音源处理跟练

| 功能点 | 适配度 / 工作量 | 评估理由 | 实现思路 |
|---|---|---|---|
| 变速不变调（原曲降速跟练） | 高价值 / medium-large | 需 time-stretch 算法。红线注意：常见库 SoundTouch 为 LGPL，与「只引 Apache/MIT」冲突 → 建议自研 WSOLA（数百行）；依赖 F601 PCM 抽取 | 用户选本地音频 → PCM → WSOLA 变速 → 与 F401 跟练判定联动（降速练→逐级提速，达成速度写 Room）；先承诺「慢速练习可用」，不承诺原速高保真 |
| 变调（±12 半音） | 中 / medium | 与上一条同属一个算法包（stretch+pitch 两参数），resample 变调简单但联动变速要一起做 | 同上算法包内出 pitch 参数；变调后喂给移调建议 |
| BPM 自动检测 + 智能节拍器同步 click | 中高 / medium | onset+自相关检测在 F603 节拍量化基建里已有雏形，可复用 | 检测 BPM/重拍位 → 叠加 click 轨与原曲对拍，练习室里「原曲+节拍器」同播 |
| 音源分离（人声/鼓/贝斯/吉他） | 低（端侧）/ large | 端侧需 Demucs 类大模型，算力与包体不可行；云端方案 F604 已决策不上线 | 暂不做；替代口径见下条（近似消音） |
| 立体声场扫描隔离/消音单乐器（Riffstation 思路） | 中 / medium | 纯 DSP：中/侧（M/S）编码+频段滤波可做近似「吉他减法器」，零模型但效果有限、需诚实标注 | 对立体声素材做 M/S 分离+滤波实验，UI 明确标「近似，非 AI 分离」 |
| 循环难点 + 节拍同步 loop | 高 / small | 与播放器循环同源 | 音频 loop 与谱面 loop 二选一或联动（选段按钮复用） |
| 歌曲调号检测 | 高 / small-medium | Krumhansl 类算法基于 chroma，与和弦检测共用特征 | 显示调号，喂给乐理问答与移调建议，让 F206 更「有据」 |

## 9. 汇总：Top 8 推荐（按价值/成本比排序）

| # | 推荐功能 | 出处 | 适配度 | 工作量 | 短板标注 | 一句话理由 |
|---|---|---|---|---|---|---|
| 1 | **谱面整体播放 + 光标跟随/自动滚动** | Songsterr | 高 | small-medium | ★补「谱面整体播放」短板 | 目前只有点按试听，整曲播放是「能用」的底线；alphaTab 现成能力，接线即得，是全表性价比之最 |
| 2 | **速度训练：段落循环 + 渐进提速（Speed Trainer）** | Guitar Pro / Soundbrenner | 高 | small-medium | ★补「速度训练」短板 | 电吉他自学核心诉求；依赖 #1 的 loop 通道，SpeedRamp 一处实现两处复用，达成速度入 Room 形成成长曲线 |
| 3 | **和弦库：和弦图 + 指法 + 试听** | GuitarTuna / Fender Tune / UG | 高 | small-medium | ★补「和弦库」短板 | 静态数据+Canvas+TP 试听，无模型依赖；冷门和弦 LLM 兜底过 F209 校验，保证诚实口径 |
| 4 | **调音器强化：26 种调弦预设 + 自动认弦 + 音分表盘** | GuitarTuna / Fender Tune | 高 | small | — | 每天都用的高频工具，成本极低体验提升明显；GP 谱调弦标记直通预设是本项目独有的联动点 |
| 5 | **节拍器高级化：细分/重音 pattern + 预设 + count-in + 渐变提速** | Soundbrenner | 高 | small-medium | — | F105 目前只有一根 BPM 针，升到专业口径只需数据结构升级；与 #2 共享 SpeedRamp/count-in 组件 |
| 6 | **游戏化判定反馈：星级/连击/错音分布** | Yousician | 高 | small-medium | — | F401 判定已有，评价层直接复用；补「练了有没有效果」的激励闭环，并给 F501 周复盘提供更丰富素材 |
| 7 | **AI 今日练习单 + 「下一步」推荐** | JustinGuitar / Drumeo / Yousician | 高 | medium | — | LLM 网关+Room 是竞品没有的组合，内容可个性化（竞品内容固定）——本项目差异化主张的最佳落点 |
| 8 | **原曲变速不变调跟练（WSOLA 自研）+ BPM 检测 click** | Moises / Riffstation | 中高 | medium-large | — | 跟练真曲刚需；先做 BPM 检测+click（复用 F603 雏形，small），再攻 stretch（注意 LGPL 红线，自研 WSOLA） |

**次优先（Top 9-12）**：分轨 Solo/Mute（GP 多轨现成）→ 谱面移调/简化（F206 复用）→ 1 分钟和弦切换计时器 → TD→MIDI/PDF 导出。
**明确不做/暂不做**：原曲官方音源同步（版权）、AI 链接生成谱（云端+法务，与 F604 决策一致）、端侧音源分离（算力）、社区排行（需后端）、多设备同步（场景小众）。

## 10. 风险与诚实口径

- 信源多为下载站转述的产品描述，曲库量/精度/功能上限（如 Songsterr 15% 速度、Riffstation 80% 精度）均为宣传口径，**立项前用官方文档或真机复核**。
- time-stretch 自研的质量风险：先承诺「降速练习可用」，不承诺原速高保真；避开 LGPL 依赖是硬约束（AGENTS.md 红线）。
